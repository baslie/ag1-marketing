# AG1 Marketing

Как Athletic Greens (AG1) построил маркетинг: 12 статей 2022–2026 годов в переводе на русский, с резюме и ключевыми выводами.

**Сайт:** https://roman-purtow.ru/ag1-marketing/

## Что внутри

- **AG1 в цифрах** — таймлайн на первом экране: от одного продукта на свои деньги в 2010 году до $600 млн выручки и 2 700+ магазинов в 2026-м.
- **Главное из всех статей** — 10 выводов: подкасты, инфлюенсеры, атрибуция, один продукт, ребрендинг, наука, розница.
- **AG1 в 2026 году и уроки для России** — что изменилось за 2025–2026, какие механики переносить, чего не копировать, законы РФ (маркировка, реклама БАД, 376-ФЗ об автоподписках).
- **Выжимка для RUNGEL** — мой взгляд, что из опыта AG1 перенести в томский бренд энергетических гелей RUNGEL: посадочные статьи, адвокаты бренда, именные страницы и прозрачные выплаты. Две инфографики — «Маховик адвокатов» и «Лестница мотивации партнёров».
- **Словарь терминов** — ~80 маркетинговых, научных и юридических терминов: пояснение всплывает при наведении или нажатии на подчёркнутое слово, полный список — внизу страницы.
- **12 статей** Marketing Brew, Retail Brew, Modern Retail, Inc., Adweek и других изданий: полный перевод, резюме, ссылка на оригинал.

Сайт статический и без сборки: откройте `index.html` в браузере прямо из папки. Из внешних ресурсов — только шрифты Google Fonts (Unbounded, Geologica, Golos Text), без сети включаются системные. Есть тёмная тема, мобильная версия и плавная прокрутка [Lenis](https://github.com/darkroomengineering/lenis) 1.3.26 — на тач-устройствах прокрутка остаётся нативной.

## Структура

```
index.html                   разметка и тексты статей
assets/css/style.css         стили: токены палитры, темы, разделы по ходу страницы
assets/js/app.js             тема, шапка, прогресс чтения, счётчик таймлайна, буквица, появление блоков, боковое оглавление
assets/js/glossary-terms.js  словарь: термины, шаблоны поиска, определения
assets/js/glossary.js        разметка терминов в тексте, раздел «Словарь», подсказки
assets/vendor/               Lenis 1.3.26 (lenis.min.js, lenis.css)
assets/img/                  иллюстрации статей: <id статьи>-<номер>.webp
```

Новый термин словаря — строка в `glossary-terms.js`, разметка в тексте и раздел «Словарь» соберутся сами.

## Права

Переводы сделаны для ознакомления. Права на оригинальные тексты и изображения принадлежат изданиям, указанным на сайте.
